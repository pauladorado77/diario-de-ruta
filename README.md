# Diario de ruta

Web para seguir en directo el viaje familiar por Francia, Mónaco e Italia (10–18 oct 2026).

- Web: https://pauladorado77.github.io/diario-de-ruta/
- Datos, fotos y comentarios: Supabase (`config.js`). El script `supabase/setup.sql` crea las tablas, el espacio de fotos y las reglas de acceso.
- Los viajeros entran desde «Acceso viajeros» al pie de la página para añadir paradas y subir fotos. Cualquiera puede ver y comentar.
